## 🚀 Як запустити проєкт локально

1. **Клонуй репозиторій cобі на ПК:**
   ```bash
   git clone [https://github.com/diliri/javascript-portfolio.git](https://github.com/diliri/javascript-portfolio.git)
   ```
2. **Перейди у папку проєкту:**
   ```bash
   cd javascript-portfolio
   ```
3. **Встанови залежності (якщо використовується Vite/npm):**
   ```bash
   npm install
   ```
4. **Запусти локальний сервер розробки:**
   ```bash
   npm run dev
   ```
